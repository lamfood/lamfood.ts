## نمای کلی

یک برنامهٔ تک‌صفحه‌ای (SPA) با دو بخش:

- **بخش عمومی (منو):** نمایش منوی رستوران به تفکیک دسته‌بندی، جستجوی زنده، سبد خرید و اطلاعات تماس.
- **پنل مدیریت (`/admin`):** مدیریت آیتم‌های منو، آپلود تصویر، و تنظیمات رستوران — از جمله رنگ‌ها و ظاهر.

هر چیزی که در پنل ذخیره کنید، **بلافاصله** در صفحهٔ منو اعمال می‌شود.

---

## ✨ امکانات

### بخش عمومی (منو)

- نمایش منو به تفکیک دسته‌بندی (صبحانه، برگر، پیتزا، پاستا، دسر، نوشیدنی، قهوه و …)
- جستجوی زنده در آیتم‌های منو
- سبد خرید با ذخیره در `localStorage`
- نمایش وضعیت **باز/بسته** بر اساس ساعت کاری
- صفحهٔ اطلاعات (موقعیت مکانی، تماس، اینستاگرام، اسنپ‌فود)
- **رنگ‌بندی پویا** مبتنی بر تنظیمات

### پنل مدیریت (`/admin`)

- ورود امن با رمز عبور hash شده با **scrypt**
- مدیریت کامل آیتم‌های منو (افزودن / ویرایش / حذف / ترتیب / در دسترس بودن)
- آپلود تصویر
- مدیریت تنظیمات رستوران (نام، اطلاعات تماس، لوگو، …)
- **تغییر رنگ‌ها و ظاهر** به‌صورت زنده
- محافظت در برابر حملات brute-force و CSRF

## 🚀 راه‌اندازی

### پیش‌نیازها

- [Bun](https://bun.sh) (نسخهٔ ۱.۳ به بالا) — پروژه مبتنی بر Bun است.

### اجرا در محیط توسعه

```bash
# ۱) نصب وابستگی‌ها
bun install

# ۲) تنظیم متغیر محیطی دیتابیس (محتوای فایل .env)
#    DATABASE_URL="file:../db/custom.db"

# ۳) ایجاد/به‌روزرسانی جدول‌های دیتابیس
bun run db:push

# ۴) (اختیاری) پرکردن منو با دادهٔ نمونه
bun scripts/seed.ts

# ۵) اجرای سرور توسعه
bun run dev
```

سپس باز کنید: **http://localhost:3000** — پنل مدیریت: **http://localhost:3000/admin**

> **نکته برای ویندوز:** اسکریپت `dev` از `tee` (دستور لینوکس) استفاده می‌کند که در ویندوز موجود نیست. به‌جای آن اجرا کنید:
>
> ```bash
> bunx next dev -p 3000
> ```

### اجرا در تولید

```bash
bun install
bun run db:push
bun run build    # خروجی standalone + کپی استاتیک/public
bun run start    # اجرای سرور تولید روی پورت ۳۰۰۰
```

## 🔐 مدیریت و امنیت

- نام کاربری پیش‌فرض: `admin`
- تغییر رمز عبور:

```bash
bun scripts/set-admin-password.ts <رمز-جدید>   # حداقل ۸ کاراکتر
```

- رمز عبور به‌صورت hash (scrypt) و اطلاعات مدیریت در `config.json` ذخیره می‌شوند.
- محدودسازی تلاش ورود (brute-force) و بررسی CSRF برای درخواست‌های تغییر داده فعال است.

### بازنشانی منو (دادهٔ نمونه)

```bash
bun scripts/seed.ts --force   # حذف همهٔ آیتم‌ها و seed مجدد
```

## ⚙️ پیکربندی

تنظیمات اصلی رستوران و مدیریت در فایل [config.json](./config.json) قرار دارند.

### تنظیمات رستوران (`restaurant`)

| کلید                          | مقدار فعلی                                                |
| ----------------------------- | --------------------------------------------------------- |
| `name`                        | لم‌فود                                                    |
| `nameEn`                      | LamFood                                                   |
| `tagline`                     | شعار خیلی خفن(:                                           |
| `logo`                        | `/uploads/logo.png`                                       |
| `heroImage`                   | `/uploads/hero.png`                                       |
| `about`                       | متن معرفی رستوران                                         |
| `phone`                       | `0919392595`                                              |
| `whatsapp`                    | `989190392595`                                            |
| `address`                     | پردیس، بلوار شهدای خدمت، بلوار شهید قاسم سلیمانی، پلاک ۱۶ |
| `location`                    | مختصات روی نقشه (`lat` / `lng`)                           |
| `openTimeText`                | همه‌روزه از ۷:۳۰ صبح تا ۱۱:۳۰ شب                          |
| `openHourFrom` / `openHourTo` | `07:30` / `23:30`                                         |
| `instagram`                   | لینک اینستاگرام                                           |
| `snappfood`                   | لینک اسنپ‌فود                                             |
| `theme`                       | رنگ‌های ظاهری سایت                                        |

### رنگ‌ها و ظاهر (`restaurant.theme`)

قابل تغییر از پنل مدیریت (بخش **«رنگ‌ها و ظاهر»**) یا مستقیم در `config.json`:

| کلید                | مقدار پیش‌فرض | نقش                     |
| ------------------- | ------------- | ----------------------- |
| `primary`           | `#166b73`     | رنگ اصلی (دکمه‌ها، هدر) |
| `primaryForeground` | `#fbfffe`     | رنگ متن روی رنگ اصلی    |
| `accent`            | `#faa916`     | رنگ هایلایت/تاکید       |
| `accentForeground`  | `#2b1d02`     | رنگ متن روی اکسنت       |
| `background`        | `#fbfffe`     | رنگ پس‌زمینه            |
| `foreground`        | `#0d3b41`     | رنگ متن اصلی            |

> سایر رنگ‌ها (`secondary`، `muted`، `border`، `ring` و …) به‌صورت خودکار از رنگ اصلی و پس‌زمینه ساخته می‌شوند تا ظاهر یکدست بماند.

### حساب مدیریت (`admin`)

- `admin.username`: نام کاربری ورود به پنل (پیش‌فرض `admin`)
- `admin.passwordHash`: رمز عبور hash شده با scrypt

### سایر

- `sessionSecret`: کلید امضای سشن‌ها (نباید به اشتراک گذاشته شود)

> آیتم‌های منو در دیتابیس SQLite ذخیره می‌شوند، اما مشخصات رستوران و حساب مدیریت در `config.json` (که با پنل به‌روزرسانی می‌شود).
