# لم‌فود | LamFood

وب‌سایت منوی رستوران و مدیریت لم‌فود. یک اپلیکیشن تک‌صفحه‌ای برای نمایش منوی رستوران، سبد خرید، و پنل مدیریت محتوا.

- تماس با لم‌فود: `0919392595`
- موقعیت: پردیس، بلوار شهدای خدمت، بلوار شهید قاسم سلیمانی، پلاک ۱۶
- ساعات کاری: همه‌روزه ۷:۳۰ صبح تا ۱۱:۳۰ شب

## امکانات

**بخش عمومی (منو)**

- نمایش منوی رستوران به تفکیک دسته‌بندی (صبحانه، برگر، پیتزا، پاستا، دسر، نوشیدنی، قهوه و غیره)
- جستجوی زنده در منو
- سبد خرید (با ذخیره در localStorage)
- نمایش وضعیت باز/بسته بودن رستوران بر اساس ساعت کاری تهران
- نمایش صفحه‌ی اطلاعات (موقعیت مکانی، تماس، اینستاگرام، اسنپ‌فود)

**پنل مدیریت** (`/admin`)

- ورود با نام کاربری و رمز عبور (hash شده با scrypt)
- مدیریت آیتم‌های منو (افزودن / ویرایش / حذف / ترتیب / در دسترس بودن)
- آپلود تصویر
- مدیریت تنظیمات رستوران (نام، اطلاعات تماس، لوگو و غیره)
- محافظت در برابر حملات brute-force و CSRF

## پیش‌نیازها

- [Bun](https://bun.sh) (نسخه‌ی ۱.۳ به بالا)

> این پروژه با **Bun** ساخته شده و اسکریپت‌ها بر اساس `bun run` هستند.

## اجرا در محیط توسعه

```bash
# ۱) نصب وابستگی‌ها
bun install

# ۲) تنظیم متغیر محیطی دیتابیس
#    فایل .env بسازید و این خط را اضافه کنید:
#    DATABASE_URL="file:./db/custom.db"

# ۳) ایجاد / به‌روزرسانی جدول‌های دیتابیس
bun run db:push

# ۴) (اختیاری) پر کردن منو با داده‌ی نمونه
bun scripts/seed.ts

# ۵) اجرای سرور توسعه
bun run dev
```

سپس مرورگر را باز کنید: **http://localhost:3000**

پنل مدیریت در: **http://localhost:3000/admin**

> **نکته برای ویندوز:** اسکریپت `dev` در `package.json` از `tee` (دستور لینوکس) استفاده می‌کند که در ویندوز موجود نیست. به‌جای `bun run dev` این دستور را اجرا کنید:
>
> ```bash
> bunx next dev -p 3000
> ```

### تغییر رمز عبور مدیریت

```bash
bun scripts/set-admin-password.ts <رمز-جدید>   # حداقل ۸ کاراکتر
```

نام کاربری پیش‌فرض مدیریت `admin` است. تنظیمات مدیریت و رمز در فایل `config.json` ذخیره می‌شوند.

### بازنشانی منو (داده‌ی نمونه)

در صورت نیاز به پر کردن مجدد منو با داده‌ی نمونه:

```bash
bun scripts/seed.ts --force   # حذف همه‌ی آیتم‌ها و seed مجدد
```

## پیکربندی

تنظیمات اصلی رستوران و مدیریت در فایل [config.json](./config.json) قرار دارند:

**تنظیمات رستوران (`restaurant`)**

| کلید                          | مقدار فعلی                                                |
| ----------------------------- | --------------------------------------------------------- |
| `name`                        | لم‌فود                                                    |
| `nameEn`                      | LamFood                                                   |
| `tagline`                     | شعار خیلی خفن(:                                           |
| `logo`                        | `/uploads/logo.png`                                       |
| `heroImage`                   | `/uploads/hero.png`                                       |
| `about`                       | متن معرفی رستوران                                         |
| `phone`                       | `0919392595`                                              |
| `whatsapp`                    | `989190392595`                                            |
| `address`                     | پردیس، بلوار شهدای خدمت، بلوار شهید قاسم سلیمانی، پلاک ۱۶ |
| `location`                    | مختصات روی نقشه (`lat` / `lng`)                           |
| `openTimeText`                | همه‌روزه از ۷:۳۰ صبح تا ۱۱:۳۰ شب                          |
| `openHourFrom` / `openHourTo` | `07:30` / `23:30`                                         |
| `instagram`                   | لینک اینستاگرام                                           |
| `snappfood`                   | لینک اسنپ‌فود                                             |
| `theme`                       | رنگ‌های ظاهری سایت                                        |

**رنگ‌ها و ظاهر (`restaurant.theme`)** — از پنل مدیریت (انگشت «رنگ‌ها و ظاهر») یا به‌صورت دستی در `config.json` قابل تغییرند:

| کلید                | مقدار پیش‌فرض | نقش                     |
| ------------------- | ------------- | ----------------------- |
| `primary`           | `#166b73`     | رنگ اصلی (دکمه‌ها، هدر) |
| `primaryForeground` | `#fbfffe`     | رنگ متن روی رنگ اصلی    |
| `accent`            | `#faa916`     | رنگ هایلایت/تاکید       |
| `accentForeground`  | `#2b1d02`     | رنگ متن روی اکسنت       |
| `background`        | `#fbfffe`     | رنگ پس‌زمینه            |
| `foreground`        | `#0d3b41`     | رنگ متن اصلی            |

> سایر رنگ‌ها (secondary، muted، border، ring و …) به‌صورت خودکار از رنگ اصلی و پس‌زمینه ساخته می‌شوند تا ظاهر یکدست بماند.

**حساب مدیریت (`admin`)**

- `admin.username`: نام کاربری ورود به پنل (پیش‌فرض `admin`)
- `admin.passwordHash`: رمز عبور hash شده با scrypt

**سایر**

- `sessionSecret`: کلید امضای سشن‌ها (که نباید به اشتراک گذاشته شود)

> وقتی تنظیمات را با پنل مدیریت تغییر می‌دهید، همین فایل `config.json` به‌روزرسانی می‌شود.

محتوای منو (آیتم‌ها) از طریق پنل مدیریت مدیریت می‌شود و در دیتابیس SQLite ذخیره می‌گردد؛ اما مشخصات رستوران و حساب مدیریت در `config.json` ذخیره می‌شوند.
